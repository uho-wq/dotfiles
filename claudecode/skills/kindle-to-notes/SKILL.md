# kindle-to-notes: Kindle ハイライトを Notion ページ先頭の読書メモにまとめる

Notion ページ URL を受け取り、そのページ内の Kindle ハイライトを読んで読書メモを組み立て、
**同じページの一番上**に書き足す。別ページは作らない。

## 使い方

```
/kindle-to-notes https://www.notion.so/xxxxxxxx
```

引数が URL でない、または引数なしのときは、対象ページの URL を尋ねて止まる。
キーワードからの書籍検索はしない（URL を人が選ぶ前提）。

---

## ワークフロー

### Step 1: Notion の記法仕様を読む

ページに書き込む前に、`notion-fetch` に `id: "notion://docs/enhanced-markdown-spec"` を渡して
enhanced Markdown の仕様を読む。記法を推測で書かない。

### Step 2: 対象ページの取得

`notion-fetch` に受け取った URL を渡し、ページ全体を取得する。取得結果から拾うもの:

- 書名（ページタイトル。データベース行なら title プロパティ）
- 著者（プロパティまたは本文冒頭の記載。見つからなければ空欄のまま進める）
- ハイライト本文すべて
- 既に読書メモが先頭にあるか（`## 読書メモ` 見出しの有無）

**取得の欠落を必ず確認する。** `truncated` が true、`unknown_block_count` が 0 より大きい、
`unknown_block_ids` が空でない場合、ハイライトの一部が読めていない。
その旨を報告し、再取得するか、読めた範囲だけでまとめてよいかユーザーに確認する。

ハイライトが 0 件なら「材料なし」と報告して終了する。1〜2件しかないときは
「ノート化するには材料が少ない」と伝え、続けるか確認する。

### Step 3: 読書メモの下書き

以下の形で組み立てる。見出しレベルは H2（読書メモ）と H3（各セクション）。

```markdown
## 読書メモ ({YYYY-MM-DD})

対象: 『{書名}』（{著者}） / ハイライト {N}件

### 結論

{本の中心的な主張を自分の言葉で2〜3文に要約}

### 背景

{その主張が置かれている文脈・問題意識}

### 根拠

- {ハイライトから読み取れる主張・論点を箇条書き。重要な箇所は引用を添える}

### 考察

{ハイライト同士の繋がりから言えること。ハイライトに書かれていない推論だと明示する}

### 反論・留保

- ハイライト{N}件からの抽出であり、書籍全体の主張を網羅していない
- {その他、主張の限界や偏りの可能性}

### 次の問い

- {このメモから派生する問い}

---
```

末尾の `---`（区切り線）で、元のハイライトとの境界を作る。

### Step 4: 下書きの承認

下書き全文をユーザーに提示し、承認を得てから書き込む。ユーザーが修正を求めたら
直してもう一度出す。承認なしに Notion を書き換えない。

### Step 5: ページ先頭への書き込み

**既存の読書メモがない場合** — `notion-update-page` で先頭に差し込む:

```
command: "insert_content"
position: { "type": "start" }
content: {Step 3 の Markdown}
```

**既存の読書メモがある場合** — 差し替える:

1. Step 2 の取得結果から、`## 読書メモ` 見出しから直後の `---` までを**一字一句そのまま**コピーし、`old_str` にする
2. `new_str` に新しい読書メモ（同じく末尾 `---` まで）を入れる
3. `command: "update_content"` で `content_updates` に1件渡す

既存メモの範囲が取得結果から一意に特定できないときは、書き換えずに
「どこを差し替えるか判断できない」と報告する。推測で `old_str` を作らない。

### Step 6: 結果の報告

書き込んだページの URL と、「結論」「次の問い」の要約を提示する。

## 注意事項

- **元のハイライト本文は編集・削除しない** — 自動同期先であり原文のまま保持する。
  `replace_content` は使わない。`allow_deleting_content` は常に false のままにする
- **書き込みは1ページにつき1つの読書メモだけ** — 2つ目を積み上げず、既存分を差し替える
- **ページプロパティは触らない** — タグやステータスの更新はユーザーが明示的に頼んだときだけ
- **自分の言葉でまとめる** — ハイライトの羅列にしない。引用するなら「なぜ重要か」を添える
- **ハイライトは抜粋にすぎない** — 文脈は原典確認が必要である旨を「反論・留保」に必ず含める
- **`allow_async` は false にする** — 書き込み直後に結果を確認するため。
  async_task が返ったら `notion-get-async-task` で succeeded を待ってから報告する
