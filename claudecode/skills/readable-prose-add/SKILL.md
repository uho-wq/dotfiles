# readable-prose に語を登録する

このスキルは独立したサブエージェントで実行される。呼び出し元の会話履歴は見えない。判断材料は引数だけ。

対象ファイル: `~/git/dotfiles/claudecode/skills/readable-prose/SKILL.md`（`~/.claude/skills/readable-prose/` はここへ解決される）。

登録先は既存の節のどれか1つ。節を新設するのは、どの節にも収まらないときだけ。

## 手順

1. **語を確定する。** 引数に渡された語をそのまま対象にする。語尾・構文パターン（「単に〜ではなく」型）も対象。引数が空なら、登録したい表現を引数で渡すよう1文で返して終了する（会話を遡って推測しない）。
2. **重複を調べる。** 対象ファイルを grep する。同じ語や同じ意味の項目があれば、その行を示して終了する。
3. **節を選ぶ。** 表を上から順に当てる。最初に当たった節に置く。

   | 語の性質 | 登録先 |
   | --- | --- |
   | 動作を名詞で包む（「〜を行う」型）で、動詞に戻せる | §1-3 の名詞化→動詞 表 |
   | 語順・読点・助詞の癖（「が」の乱用など） | §2 「その他」 |
   | 情報を運ばない定型句 | §4 の該当カテゴリ（前置き／締め／中身のない強調・列挙／冗長・名詞化／空虚な形容／作業実況／構文の癖） |
   | 上のどれにも当たらない | §4 に新カテゴリを1つ作る。見出しは既存と同じ粒度（名詞2〜4語） |

4. **置き換えを決める。** ユーザーが指定していなければ自分で決める。削るだけで済む語は置き換えなし。置き換えがある語は既存の書式 `「〜が挙げられます」（→「〜です」）` に合わせる。
5. **1行追加する。** 周囲の箇条書きと同じ記法・同じ抽象度で書く。§5 のセルフチェックと frontmatter の description は変えない。
6. **結果を報告する。** 追加した行と節名だけを返す。呼び出し元にはこの報告しか渡らないので、調査の経過や読んだファイルの内容は書かない。判断に迷った節選択があれば、その理由を1文添える。

## 完了条件

対象ファイルに新しい行が1行だけ増え、その行が選んだ節の既存項目と同じ書式になっている。
